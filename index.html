02 · Agentic AI

Agents that run the whole workflow, not a chat window.

An agent earns its place when it carries a real process end to end — and hands the decision to a person.

  • Xiya runs a fully autonomous interview: it asks its own follow-ups, scores against a rubric and explains its recommendation.
  • Orchestration in Python and FastAPI on the Claude API and Agent SDK.
  • Workflow automation that turns multi-step manual processes into agent runs.
End to endXiya runs the full interview; people make the call

03 · Retrieval-augmented generation

Answers grounded in your data, not the model's memory.

Retrieval is what makes a model useful on a company's own information — so it gets the same care as the model itself.

  • RAG over candidate and job data powers Tulifo's matching.
  • The verified pool matches pre-interviewed candidates to employers whose role fits.
GroundedTulifo matching runs on real candidate and job data

RAG pipelines · PostgreSQL · Redis

Ingest → Chunk → Embed → Retrieve → Generate

04 · LLMs in production

Models chosen, trained and shipped like any other system.

Model choice, training and cost are engineering decisions — owned, measured and documented.

  • Own model selection at Tulifo: in-house Xiya and the open Chittu models alongside Anthropic and OpenAI.
  • Fine-tuned Chittu Guard from Qwen3-4B with MLX, and trained Chittu Story from scratch on 2.33M stories.
  • Every Chittu release ships with a model card listing its evaluations and known failures.
